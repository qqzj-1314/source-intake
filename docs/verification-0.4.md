## 产品流程

- Codex 内的实际面板通过隔离 harness 创建两个同编号工作包；按编号、标题均返回两个独立目录，不覆盖或合并；无匹配时显示 0 项。此项为面板及真实 MCP 处理器验证，不等于再次验证实际 Codex 插件侧栏挂载。
- Qoder CLI 的真实模型会话调用 intake_list_requirements，再调用 intake_context；根据项目根目录找回先前版本创建的唯一需求，补充提示词原文一致。
- 索引覆盖大小写查询、同编号多包、损坏 JSON、手工创建目录、目录链接越界、返回数量与扫描数量上限。
- 上下文读取覆盖有界迭代枚举、目录/深度限制、单文件和总哈希预算；使用会在超限枚举时报错的迭代器，证明不会先读取整个目录才截断。
